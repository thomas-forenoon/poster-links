ADE Discovery Methods

This document describes the experiment in plain language for readers who do not need code access.

1) What this study is trying to answer

The task in this study is a control task:

Given a drug-event pair, predict whether it is a FAERS signal pair or a FAERS non-signal pair.

This is not PU-learning discovery on unobserved pairs. It is a supervised classification task on observed FAERS pairs.

2) Data used

We combine three sources:

  • FAERS: spontaneous adverse-event reports
  • OFFSIDES: side-effect evidence from a separate source
  • SIDER: known side effects from labels

3) How labels were defined (exact rule)

A drug-event pair was labelled as a positive signal if all of the following were true:

  • ROR > 2.0
  • q_fdr < 0.05
  • a >= 5 reports

In short:

  • Positive class (y=1): statistically strong FAERS signal with enough support
  • Negative class (y=0): observed in FAERS but does not meet the signal rule, with enough support

Quick definitions:

  • ROR (Reporting Odds Ratio): effect size for disproportionality
  • q_fdr: multiple-testing-corrected p-value
  • a: number of FAERS cases for that drug-event pair

Class sampling in this setup used roughly a 1:1 negative-to-positive ratio.

4) Leakage control (what was removed and how it was checked)

Leakage means the model could “peek” at variables that directly encode the target rule.

To prevent that, we removed all FAERS signal-rule-derived predictors from training inputs, including:

  • FAERS disproportionality statistics (for example ROR/PRR/IC, p-values, adjusted p-values)
  • FAERS report-count style predictors used by the signal rule
  • Direct FAERS signal indicators

We kept:

  • Graph structure (which entities are connected)
  • Non-label-source covariates from OFFSIDES and SIDER

Leakage audit:

  • Before training, schema checks rejected forbidden FAERS signal-rule feature patterns.
  • Feature manifests were exported so the final input schema was auditable.

Important limitation: In configurations that include a FAERS graph, FAERS co-reporting structure still contributes through graph topology. This is not the same as feeding FAERS signal-rule statistics directly as features.

5) Model configurations compared

We evaluated five configurations:

  • Edge-only baseline (full features): no graph message passing
  • Graph + full features
  • Graph + flags only (remove numeric OFFSIDES evidence values)
  • No FAERS graph + full features
  • No FAERS graph + flags only

6) Metrics reported

  • AUROC: ranking quality across thresholds
  • AUPR: precision-recall quality (important with class imbalance)
  • ECE: calibration error (lower is better)
  • Brier score: probabilistic accuracy/calibration score (lower is better)
  • Uncertainty on safe: mean predictive entropy for y=0 (non-signal) pairs
  • Uncertainty on unknown: mean predictive entropy for y=1 (signal) pairs

Recommended claim wording:

“MC-dropout was used to probe predictive uncertainty on the control task; calibration differences versus deterministic inference were mixed in this setup.”

9) One-paragraph methods text (poster-ready)

“We evaluated a FAERS control task where the model predicts whether an observed drug-event pair is a FAERS signal. Positive labels were defined as pairs meeting a disproportionality rule (ROR > 2.0, q_fdr < 0.05, a >= 5), and negatives were observed non-signal pairs with sufficient support. To control leakage, we excluded all FAERS signal-rule-derived predictors (for example disproportionality statistics and direct signal indicators) from model inputs, while retaining graph topology and non-label-source covariates (OFFSIDES/SIDER). We compared an edge-only baseline against graph variants with and without FAERS edges and with full vs flag-only covariates, and reported AUROC, AUPR, ECE, Brier, and class-conditional predictive entropy. Graph models outperformed edge-only baselines, while deterministic-vs-MC-dropout calibration differences were mixed, supporting MC-dropout as an uncertainty probe rather than a consistent calibration improvement in this setup.”
